# Счётчик калорий

---
**Пользователь взаимодействует с приложением через консольный интерфейс, который позволяет выполнить одно из действий по выбору:**

*<br>1. ввести количество шагов за определённый день;
<br>2. изменить цель по количеству шагов в день;
<br>3. напечатать статистику за определённый месяц;
<br>4. выйти из приложения.*
