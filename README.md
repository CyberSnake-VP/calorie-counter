# Счётчик калорий

---
**Пользователь взаимодействует с приложением через консольный интерфейс, который позволяет выполнить одно из действий по выбору:
<br>ввести количество шагов за определённый день;
<br>1. изменить цель по количеству шагов в день;
<br>2. напечатать статистику за определённый месяц;
<br>3. выйти из приложения.**
